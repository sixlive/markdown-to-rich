Privacy & Terms

Last updated October 28, 2026

Markdown to Rich Text is a free tool run by me, TJ Miller, as an individual. This page lists everything that touches a server when you use it.

What you type stays on your device

Conversion happens in your browser tab. The Markdown you type, paste or open from a file is never uploaded, logged or sent to me. The site's Content Security Policy blocks the page from sending data anywhere except the analytics server described below. The code is open source if you'd like to check.

What is collected

  • Page view counts. I run my own copy of Umami to count visits. For each page view it records the page address and title, the site that linked you here, your browser language and screen size, and works out your browser, operating system, device type and approximate location (country, region and city) from the request. It doesn't use cookies or store your IP address. It does combine your IP address and browser details with a secret that changes every month to make an anonymous visitor ID, so repeat visits within a month count as one visitor. Nothing you type is included.
  • Hosting. The site is served by Cloudflare. Like any web host, Cloudflare sees your IP address and the pages you request so it can deliver them and protect the site from abuse.

I don't sell data, run ads or use tracking cookies, and there are no accounts, so nothing ties these counts to who you are.

What is stored in your browser

Your current draft and option settings are saved in your browser's local storage so they're still there when you come back. They never leave your device. The Clear button empties the draft, and clearing your browser's site data removes it entirely.

Images in your Markdown

If your Markdown includes an image from another website, your browser loads it directly from that website, which can see your IP address like any other image request. Leave remote images out if that matters to you.
